Screen Share Training

1. SS General Principles

Screen Share bayad faghat baraye review-e yek suspicion-e moshakhas va motabeg ba policy-e server anjam shavad. Process bayad transparent, documented va fair bashad.

Dar sorat-e sabt-e session, player bayad az recording agah bashad. Recording faghat ba policy-e roshan, consent-e monaseb va baraye hadaf-e moshakhas anjam mishavad. Access be recording bayad mahdood bashad va moddat-e negahdari an moshakhas bashad.

OBS va Bandicam az jomle software haye recording hastand. Estefade az anha nabayad bedoon etela'e player ya baraye zakhire-ye private information bashad.

2. Required Tools Reference

Dar reference-e ersal shode, AnyDesk, Everything va Process Hacker name borde shode boodand. Mojoodiat-e in tools dar computer-e player nabayad be onvan-e dalil-e takhalof tafsir shavad.

  • AnyDesk: remote support tool. Faghat ba consent-e explicit va control-e player.
  • Everything: file-name search tool. Personal directory ha nabayad browse shavand.
  • Process Hacker: system monitoring tool. Process name be tanhayi proof nist.
  • OBS / Bandicam: recording tools. Recording bayad transparent va authorized bashad.

3. Minecraft Client Information

Version-e game va client momken ast az information-e mojood dar khod-e game ya settings-e mojaz-e server shenasaei shavad. Version-e Minecraft, client, mod loader va server configuration bayad dar report az ham joda sabt shavand.

F3 mitavanad information-e technical-e game ra namayesh dahad. Information-e namayesh dade shode bayad ba version-e game va context moghayese shavad. Yek version ya client name be tanhayi dalil-e takhalof nist.

4. Mods and Client Policy

Mod ha momken ast visual, performance, accessibility ya gameplay-related bashand. Hame-ye mod ha cheat nistand. Server bayad list-e allowed va restricted khod ra roshan konad.

Review-e file haye player faghat dar charchoob-e policy, consent va scope-e roshan mojaz ast. Search-e kolli dar personal files ya browse kardan-e file haye unrelated gheyre mojaz ast.

5. Temporary Files and Activity Records

Windows activity records, temporary files va recent items momken ast incomplete, ghadimi ya gheyre-daghigh bashand. Mojoodiat-e yek file be ma'na-ye ejra shodan ya estefade az an nist. Adam-e mojoodiat-e file ham proof-e pak boodan nist.

Hich moderator nabayad be sorat-e automatic az file names natije giri konad. Har observation bayad source, context, timestamp va limitation dashte bashad.

6. Process and Memory Information

Process monitoring momken ast information-e technical dar mored-e application ha namayesh dahad. Esm-e process, start time, memory entry ya string be tanhayi neshan nemidahad ke player cheating karde ast.

Extract kardan-e memory strings, jostojoo dar memory baraye peyda kardan-e private data, ya tabdil-e path haye shakhsi be evidence-e punishment dar in Academy amoozesh dade nemishavad. Agar suspicion-e technical vojood darad, case bayad be reviewer-e authorized ba process-e rasmi ersal shavad.

7. Executable and JAR File Review

File haye EXE va JAR mitavanand marboot be application, launcher, mod, library ya software-e mamooli bashand. Pas file extension be tanhayi neshan-e cheat nist.

Hich file-i nabayad bedoon source, context, version va evidence-e relevant sabab-e ban shavad. Review bayad mahdood va motabeg ba privacy policy bashad.

8. Consent and AnyDesk Safety

Player bayad ghabl az remote session az hadaf, scope, moddat va shakhs-e operator agah bashad. Consent bayad explicit va ghabele pas gereftan bashad.

Moderator nabayad password, private messages, photos, documents, financial information ya personal accounts ra darkhast ya browse konad. Player bayad control-e session ra hefz konad va betavanad an ra stop konad.

9. Final SS Report

Report-e nahayi bayad in mavared ra dashte bashad:

  • Player name va case reference.
  • Tarikh va zaman-e review.
  • Consent va scope-e review.
  • Evidence-e relevant va source-e an.
  • Limitations va ehtemal-e false positive.
  • Sharh-e player, agar marboot bashad.
  • Natije va dalil-e decision.
  • Reviewer ya senior staff-e masool.

Staff Policy

Fair Moderation

  • Har report bayad neutral va bedoon bias review shavad.
  • Player bayad forsat-e sharh dadan dashte bashad.
  • Evidence bayad relevant va ghabele verify bashad.
  • Moderator nabayad az authority-e khod estefade-ye shakhs konad.
  • Dar mored-e uncertainty, case bayad escalate shavad.
  • Personal information bayad private bemanad.
  • Har punishment bayad dalil-e documented dashte bashad.

Evidence Standards

Yek alert, process name, file name, ping, CPS, client name ya tool output be tanhayi proof-e cheating nist. Context, source, timestamps, limitations va false positive ha bayad dar nazar gerefte shavand.
